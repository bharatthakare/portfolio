# Bharat Thakare — Personal Portfolio

A responsive personal portfolio showcasing my journey as an MCA student, my projects, technical skills, learning journey, and ways to connect with me.

Built with HTML, CSS, and JavaScript, the portfolio features a modern dark theme, responsive layouts, and a clean, minimal design.

## ✨ Features

- **Responsive Design** — Adapted for desktop, tablet, and mobile screens.
- **Personal Profile Card** — Introduction, profile photo, and personal details.
- **Projects Showcase** — Highlights projects, concepts, and innovations.
- **Learning Journey** — Displays my ongoing learning and development.
- **Technical Toolkit** — Showcases technologies and skills I'm exploring.
- **Social Connections** — Links to LinkedIn, GitHub, X (Twitter), Instagram, and email.
- **Interactive Navigation** — Mobile navigation and active-section highlighting.
- **Theme Toggle** — Switches the appearance if enabled in the current implementation.
- **Contact Form** — Prepares an email draft in the visitor's default email application.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts — Manrope and DM Mono

The website uses system font fallbacks when Google Fonts are unavailable.

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` directly in your browser, or run the project using the Live Server extension.
4. Explore the portfolio and test its navigation and interactive features.

No build tools or package installation are required for the basic website.

## 🌐 Deploy on GitHub Pages

1. Push the portfolio files to a GitHub repository.
2. Open the repository on GitHub.
3. Navigate to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your main branch and the `/ (root)` folder.
6. Click **Save**.
7. Wait for GitHub Pages to publish the site, then open the URL provided in the Pages settings.

Make sure `index.html` is in the repository root for this setup.
